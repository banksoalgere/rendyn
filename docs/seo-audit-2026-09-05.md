# Rendyn SEO audit — 5 September 2026

The public homepage already serves **React UI Components for AI Coding Agents | Rendyn**. Its description, canonical, Open Graph and X metadata all use Rendyn and `https://rendyn.dev`. No DesignMCP text was found in any fetched public page HTML. Search Console confirmed the cause: its last crawled homepage HTML, dated Sep 5, 2026 at 3:32:08 AM in the console, still contains the exact DesignMCP title and Open Graph site name supplied by the user. Google selected the correct Rendyn canonical URL. The indexed title needs a fresh crawl of the updated deployment.

Changes described as fixed below are **local, built and verified**, not deployed. The checkout also contains pre-existing homepage presentation changes, which were preserved. No commits, production deployment, DNS changes or Search Console submissions were made.

## Coverage and evidence

- Crawled every URL in the live sitemap: **204 pages**, including **189 components**, the homepage, catalogue, pricing and 12 editorial pages.
- Checked 11 additional destinations: guides index, sign-in/account/consent, a legacy redirect, a filtered catalogue URL, image/favicon and deliberately invalid routes. Separately checked a valid embedded preview, HTTP-to-HTTPS and www, plus the homepage with a Googlebot user agent.
- Parsed server-rendered titles, descriptions, canonicals, robots, social metadata, headings, links and JSON-LD. Compared these with the compiled local application across **205 sitemap pages**.
- Per-page before/after evidence: [seo-audit-2026-09-05.json](./seo-audit-2026-09-05.json).

## Checks that passed in production

- All **204 sitemap URLs returned HTTP 200**, with a single matching canonical on the HTTPS Rendyn origin. No public sitemap page emitted `noindex`.
- Every sitemap page has a title, description and exactly one H1. Component content and navigation links are present in the initial HTML; the catalogue exposes links to all 189 details without requiring a crawler to interact with filters.
- `robots.txt` permits public crawling and advertises the correct sitemap. It excludes API and authentication handler paths.
- Login and consent emit `noindex, nofollow`; account redirects to sign-in. A valid embedded preview at `/component-preview/001` returns 200 with `noindex, nofollow`. These routes are excluded from the sitemap. They remain crawlable so crawlers can read `noindex`.
- Deliberately nonexistent main/component URLs return real 404 responses with `noindex`.
- `/resources/how-to-design-a-website-with-chatgpt` returns a **308** to its current `/guides/` URL.
- `http://rendyn.dev/` returns a **301** to HTTPS. The filtered catalogue canonical points to `/components`, avoiding separate canonical URLs for filter combinations.
- The homepage returns HTTP 200 and the Rendyn title for a Googlebot user agent. This is a user-agent comparison, not proof of Google's actual network access or indexed rendering.
- The social image and SVG favicon return 200. The local social image visibly says Rendyn and the favicon is an R; their existing assets were preserved.
- Existing JSON-LD parsed successfully. Component pages already provide article and breadcrumb data. No ratings, reviews or unsupported commercial claims were added.

## Performance and content assessment

Public HTML responses had a median time to first byte of approximately **101 ms** from this audit environment. Component-heavy HTML was approximately **110 KiB median**, with the largest audited page approximately **291 KiB**. These are single-run HTTP observations, not Core Web Vitals, mobile load times or a ranking score.

The homepage's six first-party stylesheets and 22 declared script/module-preload assets returned 200. The page also requests Google font stylesheets. This asset inventory does not measure dynamically loaded modules, iframe work, font downloads or interaction cost. The build reports a large-chunk warning; the preview/animation bundles deserve a measured mobile performance review before further optimization.

Google's public PageSpeed endpoint returned **429 quota exceeded**, so LCP, INP, CLS, Lighthouse scores and CrUX field data remain unverified. Use Search Console's Core Web Vitals report or an authenticated PageSpeed run to establish those measurements. Avoid claiming that a fast HTML response proves a fast interactive page.

The homepage now states what Rendyn offers in visible text near its main heading. Component titles lead with the actual component and React, rather than repeating a long Claude Code phrase on every page. The guide hub strengthens the existing editorial navigation without adding keyword-only pages. The existing guide content was inspected for metadata and navigation, not exhaustively fact-checked against every external reference. Backlinks, query demand, rankings, conversion rates and indexing coverage require data unavailable in this audit.

2. Recheck live homepage title/schema, `/guides`, representative component variants, pricing and the sitemap. Expect **205** sitemap entries for the current catalogue and guide registry.

5. Monitor title/site-name refresh and indexing coverage. Recrawling can take days to weeks; repeated requests do not accelerate it, and Google ultimately chooses its displayed titles and site names.

Relevant primary guidance: [site names](https://developers.google.com/search/docs/appearance/site-names), [title links](https://developers.google.com/search/docs/appearance/title-link), [recrawl requests](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl), [sitemap dates and canonical URLs](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [crawlable noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing).

Search Console showed no submitted sitemaps. Its Core Web Vitals report confirms insufficient usage data for both mobile and desktop; this is an unavailable field dataset, not a failing performance score.
