# Mantine Checkbox

Choose whether an option is selected.

## Installation

- Complete MIT usage examples extracted from the upstream demo code template; documentation configurator machinery is excluded.
- Mount MantineProvider once at your client application root and import @mantine/core/styles.css. The returned preview wrapper is a standalone example; reuse an existing provider when integrating.

- Copy every returned file and preserve the MIT licence notice.
- Render the returned preview.tsx example, or integrate the example into your existing provider.
