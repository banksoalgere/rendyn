# Material UI Text Fields

Present text with an appropriate hierarchy and emphasis.

## Installation

- Complete MIT example code using the pinned Material UI npm package; MUI internals and paid MUI X components are not redistributed.
- React and React DOM are required. The default Emotion styling engine is included in the dependency command.

- Copy every returned file and preserve the MIT licence notice.
- Render the returned preview.tsx example, or integrate the example into your existing provider.

Upstream: https://mui.com/material-ui/react-text-fields/
Pinned source: https://github.com/mui/material-ui/blob/fc2cbd6d57a52a95121c33eb625d6cf533dd5f43/docs/data/material/components/text-fields/BasicTextFields.tsx
