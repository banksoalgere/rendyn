# HeroUI input otp

17 published HeroUI input otp examples with complete pinned source and MIT attribution.

## Installation

- Complete MIT examples for HeroUI 2.8.10; these APIs do not target HeroUI 3.
- Mount HeroUIProvider at your client root. Configure the HeroUI Tailwind plugin and scan node_modules/@heroui/theme/dist/**/*.{js,ts,jsx,tsx}. Keep the matching Framer Motion dependency.

- Copy every returned file and preserve the MIT licence notice.
- Render the returned preview.tsx example, or integrate the example into your existing provider.
