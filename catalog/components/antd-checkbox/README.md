# Ant Design Checkbox

Choose whether an option is selected.

## Installation

- Complete MIT example compositions using the pinned antd npm package.
- Ant Design supplies component styling at runtime. Add application validation and persistence when wiring form controls to your backend.

- Copy every returned file and preserve the MIT licence notice.
- Render the returned preview.tsx example, or integrate the example into your existing provider.
