# shadcn/ui Sidebar 06

Organize application navigation and supporting controls in a side panel.

## Installation

- Copyable component source and official examples, not a dependency on a hosted registry.
- Use Tailwind CSS 4 and configure the standard shadcn semantic colour tokens (background, foreground, primary, border, input, ring, muted and accent).

- Copy every returned file and preserve the MIT licence notice.
- Render the returned preview.tsx example, or integrate the example into your existing provider.
